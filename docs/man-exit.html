exit(1)#

NAME#

exit, logout - leave the shell with status N (by default the status of the last command) (shell builtin)

SYNOPSIS#

exit [N]
logout [N]

DESCRIPTION#

Leave the shell with status N (by default the status of the last command). In a terminal window this closes the window.

SEE ALSO#

builtins(1), lsh(1)
