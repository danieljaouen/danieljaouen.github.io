The desktop (Photon)#

Photon is Lepton's graphical desktop: a Wayland compositor written in Elixir, like the rest of Lepton. It takes over the VM's display and shows windows that you move, resize and type into with the mouse and keyboard. The first window is a terminal running your shell.

photon

Run it from the console in the VM window (UTM's display, or QEMU with a display). It needs the display's framebuffer, so it doesn't start from mix lepton.shell on a Mac or over a serial console without a display.

When you quit, the text console comes back as you left it.

Terminal windows#

A terminal window runs lsh with your account, as your console does. Everything that works in a terminal works there, including le, tmux and the colours of your prompt. Resizing a window changes its rows and columns. Typing exit closes the window. Closing the window ends its shell and everything running in it, as closing a terminal does on Unix: close the System Monitor and its top stops too. Apps such as Firefox keep running. Ctrl+Shift+V pastes the clipboard.

Opening files#

open (also xdg-open, as your dotfiles call it on Linux) opens files, folders and web addresses in the app for them:

WhatOpens in
text: notes, code, configuration, any file that is UTF-8 textle, in the terminal you ran open in
images (PNG, JPEG, GIF, WebP, SVG, ...) and PDFsFirefox
a folder, such as open .Firefox, as a list of its files
a web address (https://...)Firefox
open notes.txt          # edit it in le
open photo.jpg paper.pdf
open .                  # the current folder, in Firefox
xdg-open https://trylepton.app

Firefox needs the desktop (photon or classic). If Firefox is already open, each page, image, PDF or folder opens in a new tab of it, open . too. Several files can be given at once: the text files open together in one le, and everything else opens in Firefox. open recognises a file by its contents as well as its name, so an image without an extension still opens in Firefox. Files that are neither text nor anything Firefox shows (programs, archives) aren't opened.

The clipboard#

Photon's windows share Lepton's clipboard, the one pbcopy and pbpaste, tmux's copy mode and the editor's yanks use (see System):

  • Copy in Firefox (Ctrl+C), then pbpaste in a terminal, Ctrl+Shift+V in a terminal window, C-t ] in tmux or p in le.
  • Copy in a terminal (echo hello | pbcopy, a tmux or editor copy), then Ctrl+V in Firefox.

Only text reaches Lepton's clipboard; anything else a program copies goes only to programs on the desktop.

Drag and drop#

Programs can drag things within their windows and between them: in Firefox, drag a tab along the tab bar to move it. No picture of what's dragged follows the pointer.

From a shell, inside Photon or on the console:

photon term                 # open another terminal window
photon term le notes.txt    # a window running a command
photon info                 # the display, clients and windows
photon display mirror       # with two displays: mirror them (or extend)
photon screenshot shot.png  # save the screen as a PNG
photon stop                 # quit

The classic desktop#

For something more familiar, type classic instead of photon. It's Photon with a different window manager, styled after Windows 95:

  • grey 3D window frames with a navy title bar and minimize, maximize and close buttons (double-click a title bar to maximize or restore)
  • a teal desktop with icons for Firefox, the Terminal, the Text Editor (le), the System Monitor (top), Passwords and Install PostgreSQL (which sets up the database and becomes PostgreSQL, opening psql), and one for each USB drive or SD card that is mounted: double-click one to open it
  • a taskbar with a button for each window (click to bring it to the front, click again to minimize it), the Wi-Fi signal (click it to pick a network: Wi-Fi), the Bluetooth rune (click it for your devices: Bluetooth), the volume's speaker (click it for the volume control: Sound) and a clock
  • the Start menu (click Start, or Ctrl+Esc): Firefox, Terminal, Text Editor, System Monitor, Printers (choose your default printer), Passwords (the password manager), Help and Exit Desktop

The keys from the table above work here too. Exit Desktop (or Ctrl+Alt+Backspace) returns you to the console. Lepton never starts a desktop at boot; you choose photon or classic when you want one.

More than one display#

With a second display (a second VM display, or a USB display adapter), the desktop extends across both, side by side, or mirrors the primary display (photon display mirror). Displays can come and go while it runs. See USB, hubs and displays.

Keyboards and mice plugged in while the desktop runs, directly or through a hub, work within a second.

Wayland#

Photon speaks the standard Wayland protocol on $XDG_RUNTIME_DIR/wayland-0 (/run/user/UID). It supports the core protocol and xdg-shell:

InterfaceVersionNotes
wl_compositor, wl_surface, wl_region4
wl_shm, wl_shm_pool, wl_buffer1ARGB8888 and XRGB8888, shown opaque
wl_seat, wl_pointer, wl_keyboard5US keymap (XKB), key repeat info
wl_output2
xdg_wm_base, xdg_surface, xdg_toplevel, xdg_popup1
wl_subcompositor, wl_subsurface1
wl_data_device_manager, wl_data_source, wl_data_offer3the clipboard (shared with Lepton's), drag and drop
org_kde_kwin_server_decoration_manager1Photon draws the title bars
lepton_shm1Lepton's own programs: shared memory by path

Inside Photon, terminals set WAYLAND_DISPLAY and XDG_RUNTIME_DIR, so a Wayland program that draws with shared-memory buffers can connect to it; Firefox does. Photon draws the title bar and border itself and tells GTK so (KDE's server-side decoration protocol), so GTK programs leave theirs out.

What it doesn't do yet#

  • GPU-drawn (EGL) programs, transparency, the primary selection (pasting what's selected with the middle button), touch, and HiDPI scaling.
  • Fonts other than the built-in 8x16 Terminus bitmap font and, for what it lacks (Chinese, Japanese, Korean, ...), GNU Unifont's bitmaps.
  • Japanese and Chinese input (other languages and Korean work).
  • Video drivers: programs draw with the CPU.
  • Arranging displays other than left to right, or changing a display's resolution. Wayland programs see one output, the whole desktop.
