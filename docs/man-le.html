le(1)#

NAME#

le, vi, vim, nvim, emacs, emacsclient, spacemacs, edit - the Lepton editor (Spacemacs keybindings from your dotfiles)

SYNOPSIS#

le [FILE...]

DESCRIPTION#

le is Lepton's text editor, a work-alike of Spacemacs: evil (vi) editing with the SPC leader key. It opens each FILE in a buffer (a new file is created when you save). It also answers to vi, vim, nvim, emacs, emacsclient, spacemacs and edit, so $EDITOR and git's commit messages open it.

le reads your configuration rather than running it: ~/.spacemacs and ~/.spacemacs.d/ are parsed for key bindings (define-key, evil-define-key, global-set-key), variables (setq), aliases and some functions. keys editor lists what was loaded and marks bindings it does not support.

KEYS#

The vi keys work as in Vim: motions, operators and text objects with counts, ., visual modes, u and C-r, registers, splits. Ex commands include :w, :q, :wq, :e FILE, :sp, :vsp, :s/A/B/g, :sort, :!CMD and :r !CMD. Some Spacemacs leader keys:

  • SPC f f open a file, SPC f s save.
  • SPC b b switch buffer, SPC b d close buffer.
  • SPC w / and SPC w - split, SPC w d close window, SPC w m maximise.
  • SPC p f find a file in the project, SPC s s or SPC / search.
  • SPC g s git status (magit-style: s stage, u unstage, c c commit, P p push, F p pull).
  • SPC SPC run a command by name (M-x), SPC ? list bindings.
  • SPC q q quit.

With the Spacemacs tmux layer, C-h, C-j, C-k and C-l move between windows and on into neighbouring tmux panes.

Options (-...) and +LINE arguments are accepted and ignored.

FILES#

  • ~/.spacemacs, ~/.spacemacs.d/*.el: configuration.
  • ~/.emacs.d/snippets: yasnippet snippets.

SEE ALSO#

keys(1), git(1), tmux(1), https://trylepton.app/docs/editor.html
