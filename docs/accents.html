Typing accents#

Accented letters type as on a Mac with Option, here Alt: an accent key, then the letter. On a Mac (UTM, or SSH from a Terminal set to use Option as Meta), Option is Alt.

They work everywhere you type: the text console, terminal windows, over SSH, in tmux panes, in Claude Code and other programs, and in Firefox's text fields. keyboard accents lists them. A program that uses these Alt keys itself (Claude Code's Alt+T, say) gets them after keyboard accents off; keyboard accents on brings them back. The setting is kept across reboots. Alt keys that Lepton uses (Alt+b, f, d and . in the shell, Alt+v in the pager, Alt+1, 2 and 5 in tmux) stay as they are.
