Lepton documentation#

Everything Lepton OS can do, for the version on the download page. New to Lepton? Take the Tutorial, a tour of everything from the first boot on, or start with getting started.

Guides#

  • Getting started: Download the ISO, boot it in UTM or QEMU, install it to a disk and shut it down cleanly.
  • The shell (lsh): Line editing, your zsh aliases, the starship prompt, jobs and scripting.
  • The editor (le): A Spacemacs-style editor configured from your ~/.spacemacs.
  • The multiplexer (tmux): tmux sessions, windows and panes, driven by your ~/.tmux.conf.
  • git and GitHub: A format-compatible git, your gitconfig aliases, and a gh CLI.
  • SSH: SSH keys, an ssh client, known hosts and ~/.ssh/config, for GitHub and your own servers.
  • Services (svc): Start, stop and restart long-running apps, like systemd.
  • Packages (lpm): Install Elixir and Erlang packages from hex.pm, and official updates for built-in apps.
  • Networking: DHCP, interfaces, DNS, HTTP clients, a text browser and a web server.
  • Users and sudo: Your account, logging in, sudo for administration, and managing accounts.
  • System: Processes and jobs, storage and persistence, power, the clipboard, Elixir and the self-tests.
  • The desktop (Photon): Photon, Lepton's Wayland compositor, and the classic desktop: windows on the display, with the mouse and keyboard.
  • USB, hubs and displays: USB hubs and docks, devices plugged in while Lepton runs, and second displays for the desktop (extended or mirrored).
  • USB drives and SD cards: Plug in a USB drive, stick or SD card and it's mounted under /media; eject it before you unplug it.
  • Sound: Sound cards, the volume (volume, the volume keys, the classic desktop's speaker), and playing sounds.
  • Bluetooth: Bluetooth keyboards, mice and headphones: pair and connect them from the command line or the classic desktop.
  • Firefox and other apps: Firefox, installed on demand from Alpine Linux's packages and run on the desktop.
  • Your dotfiles, applied: How Lepton reads Spacemacs, tmux, zsh, starship and git configuration.
  • Limitations: What Lepton doesn't do yet.
