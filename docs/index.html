Lepton documentation#

Everything Lepton OS can do, for the version on the download page. New to Lepton? Take the Tutorial, a tour of everything from the first boot on, or start with getting started.

Getting started#

  • Getting started: Download the ISO, boot it in UTM or QEMU, install it to a disk and shut it down cleanly.
  • Updating Lepton: Update an installed Lepton to the latest ISO, in UTM or QEMU, keeping your files, apps, accounts and settings.
  • Typing accents: "Accented letters and other characters with Alt, as with Option on a Mac: Alt+e e is é, Alt+u u is ü, Alt+n n is ñ. On the console, in terminal windows, over SSH, in tmux and in Firefox."
  • Your dotfiles, applied: How Lepton reads Spacemacs, tmux, zsh, starship and git configuration.
  • Limitations: What Lepton doesn't do yet.

Working in the shell#

  • The shell (lsh): Line editing, your zsh aliases, the starship prompt, jobs and scripting.
  • The editor (le): A Spacemacs-style editor configured from your ~/.spacemacs.
  • The multiplexer (tmux): tmux sessions, windows and panes, driven by your ~/.tmux.conf.
  • git and GitHub: A format-compatible git, your gitconfig aliases, and a gh CLI.
  • Claude Code: Run Claude Code, Anthropic's coding agent, on Lepton: install it with one command, log in, and let it work on your projects with bash, git, ripgrep, mix and elixir.

System and services#

  • Services (svc): Start, stop and restart long-running apps, like systemd.
  • Scheduled jobs (cron): Run commands at set times with crontab and the cron service.
  • Databases (PostgreSQL): PostgreSQL, the database Phoenix apps use: set up with one command (or a desktop icon), run as a service, with psql and PostgreSQL's tools.
  • Packages (lpm): Install Elixir and Erlang packages from hex.pm, and official updates for built-in apps.
  • Users and sudo: Your account, logging in, sudo for administration, and managing accounts.
  • System: Processes and jobs, storage and persistence, running out of memory, logs, power, the clipboard, Elixir and the self-tests.
  • Time and time zones: The clock is kept right with NTP, and the time zone is found from your network, or set by hand.
  • Virtual machines (vm): Run arm64 virtual machines inside Lepton with QEMU, at full speed with nested virtualization, and test Lepton inside Lepton.

Networking and the web#

  • SSH: SSH keys, an ssh client, known hosts and ~/.ssh/config, and an SSH server (keys only) to log in to Lepton.
  • Syncing files (rsync): rsync to copy and mirror directories locally, to USB drives and between machines over SSH, sending only what changed.
  • Networking: DHCP, interfaces, DNS, HTTP clients, a text browser and a web server.
  • Hosting a Phoenix application: Build and run a Phoenix app on Lepton: PostgreSQL, Mix and Hex, development with live reload, and production as a service behind httpd with HTTPS.
  • Web server and HTTPS (httpd): Serve files, put HTTPS in front of a Phoenix app (LiveView's WebSockets too), and get its certificates, local or from Let's Encrypt.
  • Proxies: Reach the internet through a proxy, or a chain of them (HTTP and SOCKS), for the web, git, packages, Firefox and SSH.

Desktop and apps#

  • The desktop (Photon): Photon, Lepton's Wayland compositor, and the classic desktop: windows on the display, with the mouse and keyboard.
  • Languages and keyboards: Type Korean, Thai, Hindi, Arabic and other languages on the desktop. Choose input sources with keyboard, switch with Super+Space, compose Hangul in Firefox, and make Caps Lock a Ctrl.
  • Sound: Sound cards, the volume (volume, the volume keys, the classic desktop's speaker), and playing sounds.
  • Firefox and other apps: Firefox, installed on demand from Alpine Linux's packages and run on the desktop.
  • Printing: Print to network printers (AirPrint, IPP Everywhere) from the shell and from Firefox, with CUPS's commands.
  • Passwords: A password manager like 1Password, on the desktop and in the shell. It keeps logins, secure notes and cards in an encrypted vault, and has one-time codes, a password generator and an audit.

Hardware#

  • USB, hubs and displays: USB hubs and docks, devices plugged in while Lepton runs, and second displays for the desktop (extended or mirrored).
  • USB drives and SD cards: Plug in a USB drive, stick or SD card and it's mounted under /media; eject it before you unplug it.
  • Bluetooth: Bluetooth keyboards, mice and headphones: pair and connect them from the command line or the classic desktop.
