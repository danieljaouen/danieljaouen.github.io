sha1sum(1)#

NAME#

sha1sum - compute SHA1 message digest

SYNOPSIS#

sha1sum [FILE...]

DESCRIPTION#

Print the SHA1 digest of each FILE (or of standard input, shown as -) in hexadecimal, followed by two spaces and the file name: the same format as GNU coreutils, so the output can be compared with published checksums.

EXIT STATUS#

0 on success, 1 if some FILE could not be read.

EXAMPLES#

sha1sum lepton.iso
echo -n hello | sha1sum

SEE ALSO#

md5sum(1), sha256sum(1), sha512sum(1), base64(1)
