userdel(1)#

NAME#

userdel, deluser - delete a user account

SYNOPSIS#

userdel [-r] NAME

DESCRIPTION#

Delete the user account NAME. Only root may delete accounts: use sudo. deluser is the same command.

OPTIONS#

  • -r: remove the account's home directory too.

SEE ALSO#

useradd(1), passwd(1)
